You are building an agent (or any client) that needs services it can pay for
programmatically. Through Rialto's catalog your agent searches in plain language,
gets back entries with exact payment terms and a real settlement track record, pays
via x402, and holds a receipt it can verify against the public ledger - all through
the MCP server, from inside the agent's own runtime.

> Design stage - the MCP server and client quickstart land here with the first
> milestone. The [architecture](/docs/architecture) describes the full loop.
